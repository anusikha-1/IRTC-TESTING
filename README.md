# IRCTC Train Ticket Booking – Manual Testing

## Project Overview
This project focuses on manual testing of the IRCTC train ticket booking website. It covers important booking workflows, functional scenarios, and validation checks.

## Testing Scope
- Train search
- Station autocomplete
- Source and destination validation
- Input validation
- Positive and negative test scenarios
- Test execution and result documentation
- Defect identification and reporting

## Tools Used
- Microsoft Excel – Test case documentation and execution tracking
- Web browser – Manual testing

## Project Files
- `IRCTC Testing.xlsx` – Test cases, execution results, assumptions, defect log, and testing evidence.

## Key Learning Outcomes
- Writing structured test cases
- Understanding positive and negative testing
- Comparing actual results with expected results
- Identifying and documenting potential defects
- Maintaining testing evidence

## Disclaimer
This is a portfolio project created for learning and demonstrating manual testing skills. Findings should be independently verified before being treated as confirmed defects.
